KAILU CREATION™ — Compact Catalog Listing Update (PC Test)

WHAT CHANGED
- Catalog cards are now shorter: cover photo collage, catalog number, category, product name, short description, selling price, MRP, discount and a gold View Catalog button.
- View Catalog opens a responsive detail window containing the photo/video gallery, rating, color choices, in-stock sizes, fabric/description, Add to Bag, Wishlist and Buy Now.
- Selecting a color or size keeps the details window open and refreshes the selected variant.
- Existing Google Sheet Catalog Feed URL, Orders Web App URL, pincode serviceability, cart and checkout code were retained.
- No changes have been uploaded to GitHub; this ZIP is intended for local PC testing first.

TEST ON WINDOWS PC
1. Extract this ZIP to a NEW folder.
2. Open the nested KAILU-CREATION-V2-main folder (the folder containing index.html).
3. If a previous local server is running, go to its Command Prompt and press Ctrl+C.
4. In File Explorer, click the address bar, type cmd, and press Enter.
5. Run: py -m http.server 8000 --bind 127.0.0.1
6. Open: http://127.0.0.1:8000/index.html

CHECK
- Catalog cards stay compact and show the gold View Catalog button.
- Click View Catalog: detail window opens with gallery, video (if available), color/size selectors and shopping actions.
- Select a size, close and reopen the detail window; selected size should remain selected.
- Test Add to Bag and Buy Now. A real test checkout may create a row in the configured Orders Google Sheet.
- Mobile check: use Chrome DevTools device toolbar or open the same local address from a phone on the same network only if you intentionally change the server bind setting. Default bind remains local-PC only.

IMPORTANT
- The old GitHub Pages website remains unchanged until you manually upload/commit this new version.
- Catalog and order web apps still depend on their Google Apps Script deployments and access settings.
