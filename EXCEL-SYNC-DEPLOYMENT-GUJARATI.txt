KAILU CREATION — Excel Catalog Sync Fix
=======================================

મૂળ કારણ
---------
આપેલી ZIPમાં catalog-sync.js હતો, પણ GitHub પર તપાસેલી હાલની KAILU-CREATION-V2/index.html હજી products-data.js પછી script.js સીધું load કરે છે અને catalog-sync.js ચલાવતું નથી. ઉપરાંત kailucreation.in માટેનું CNAME KAILU-CREATION repositoryમાં છે, જ્યારે તે repositoryની visible file listમાં Excel workbook/catalog-sync.js નહોતાં. એટલે ZIPનો Sync Code Live Domain પર publish ન થયો હતો.

આ પેકેજમાં શું છે
-----------------
1. catalog-sync.js — Websiteના જ rootમાં રહેલી `Kailu Creation Catalog List.xlsx` નો fetch અને 20-column validation.
2. index.html — cache-version બદલ્યું છે; products-data.js backup તરીકે પહેલાં load થાય છે, પછી catalog-sync.js Excel fetch/parse કરે છે અને ત્યારબાદ જ script.js load થાય છે.
3. script.js — Excel Sync સફળ હોય ત્યારે `Synced from Excel`; નિષ્ફળ જાય તો `Sync Failed — Showing Last Synced Data` અથવા `Sync Failed — Showing Backup Data` દેખાડે છે.
4. CNAME — kailucreation.in custom domain જાળવવા માટે.
5. .nojekyll — GitHub Pagesને underscore/hidden pathsને Jekyll દ્વારા process ન કરવા માટે.

Live Website અપડેટ કરવાના પગલાં
-------------------------------
1. GitHubમાં `Kaklotar9985/KAILU-CREATION` repository ખોલો. આ જ repositoryમાં `CNAME` ફાઇલ `kailucreation.in` દર્શાવે છે.
2. ZIP Extract કરો. ZIPની અંદરના `index.html`, `catalog-sync.js`, `script.js`, `products-data.js`, `Kailu Creation Catalog List.xlsx`, `style.css`, `pincode-serviceability.js`, `images/`, `videos/` અને `data/` ફાઇલો/ફોલ્ડર્સ repositoryના rootમાં Upload/Replace કરો; તેમને વધારાના subfolderની અંદર ન મૂકો.
3. `CNAME` ફાઇલને rootમાં `kailucreation.in` text સાથે જાળવો. Packageમાં આ ફાઇલ છે.
4. GitHubમાં Commit changes કરો અને Pages deploy થવા દો.
5. Live site ખોલી Hard Refresh કરો. Product Summaryમાં `Synced from Excel` દેખાવું જોઈએ. Tooltip/titleમાં sync time અને workbook URL જોવા માટે Product Summary ઉપર hover કરો (desktop).
6. નવા Products/Variants બતાવવા માટે Excelમાં ફેરફાર કરી તેને ફરીથી આ જ repositoryના rootમાં, એ જ નામ `Kailu Creation Catalog List.xlsx`થી Upload/Replace અને Commit કરો. Website પછીના Page Load/Refresh પર નવો workbook વાંચશે.

મહત્વપૂર્ણ
----------
- Computerમાં local Excel save કરવાથી GitHub Pages પરની ફાઇલ આપમેળે બદલાતી નથી. Excelને GitHub/hosting પર Upload અને Commit કરવી પડે છે. આ package browser-side sync કરે છે; તે તમારી તરફથી GitHubમાં files upload/commit કરતું નથી.
- Excelની 20 headers names (spaces/punctuation સિવાય) અને `Kailu Creation Catalog List` sheet જાળવો.
- એક જ catalogના size variant rowsમાં Category, Product Name, Color, tag, Fabric, Description અને Image/Video Links consistent રાખો. Inconsistency/duplicate SKU થાય તો sync સ્પષ્ટ error સાથે reject થશે અને છેલ્લી સારી data snapshot જાળવાશે; તે જૂના dataને `Synced from Excel` તરીકે દર્શાવશે નહીં.
- Excel CDN/Fetch નિષ્ફળ જાય તો status warning દેખાશે; last-synced browser cache અથવા bundled backup data વપરાઈ શકે.
- Google Sheets order backend (`Code.gs` / Apps Script) આ package દ્વારા આપમેળે deploy થતું નથી. હાલની deploy થયેલી Apps Script URL જ વપરાય છે.

PC LOCAL TEST — FILE:// MODE FIX
================================
જો Chrome address barમાં `C:/.../index.html` અથવા `file:///.../index.html` દેખાય, તો Excel Sync `fetch()`થી નહીં ચાલે. Updated package direct local file modeમાં Excel Picker બતાવે છે: `Ctrl + F5` કરો, પછી તાજેતરમાં Save કરેલી `Kailu Creation Catalog List.xlsx` પસંદ કરો. `Synced from Excel` જ સફળ પરિણામ છે. `Sync Failed — Showing Backup Data` આવે તો જૂનો data છે.

બીજો વિકલ્પ: `START-LOCAL-TEST.bat` ચલાવો. Browser address `http://127.0.0.1:8765/` હોવો જોઈએ. Excel આ જ folderમાં Save થયેલી હોવી જોઈએ. Save પછી Ctrl+F5 કરો.
