KAILU CREATION — Excel Catalog Sync Fix (27-10-2026)
====================================================

મૂળ કારણ (આ ZIP માંથી મળેલું)
-------------------------------
`catalog-sync.js` માં `chooseLocalWorkbookFile()` નામનું Local PC Excel picker પહેલેથી હતું, પરંતુ `start()` ક્યારેય તેને call કરતું નહોતું. તેથી Chrome માં `file:///C:/.../index.html` ખોલતાં `loadWorkbookCatalog()` file:// mode માટે error throw કરતું અને system સીધું Backup Data બતાવતું. PC પર Save કરેલી Excel પસંદ કરીને Catalog માં લાગુ કરવાની રીત વાસ્તવમાં ચલાવવામાં આવતી નહોતી.

આ સુધારામાં
------------
1. `catalog-sync.js`
   - `file://` mode ઓળખીને Local PC Excel Test panel હવે ખોલે છે.
   - User પસંદ કરેલી `.xlsx/.xlsm/.xls` ફાઇલને SheetJS વડે parse અને validate કરે છે.
   - Valid data `KAILU_APPLY_CATALOG()` દ્વારા actual Product Grid માં લાગુ કરે છે.
   - Cancel અથવા parsing failure થાય તો backup data જાળવે છે અને સ્પષ્ટ warning/log આપે છે.
2. `script.js`
   - Local file પસંદ કરીને PC test સફળ થાય ત્યારે ખોટું `Synced from Excel` label બતાવવાને બદલે `Loaded from Selected Local Excel — PC Test Only` બતાવે છે.
3. `index.html`
   - JavaScript asset query versions બદલ્યા, જેથી browser જૂની cached scripts ફરી વાપરે તેવી શક્યતા ઘટે.

PC પર કેવી રીતે Test કરવું
-------------------------
1. ZIP Extract કરો.
2. `index.html` ખોલો.
3. `KAILU CREATION — Local PC Excel Test` panel દેખાય ત્યારે તમે Update/Save કરેલી Excel ફાઇલ પસંદ કરો.
4. Product Summary માં `Loaded from Selected Local Excel — PC Test Only` દેખાય ત્યારે પસંદ કરેલી workbook લાગુ પડી છે.
5. Excel માં વધુ ફેરફાર/Save કરો તો ફરી page refresh કરીને નવી saved workbook ફરી પસંદ કરો. Browser કોઈ local file ને તમારી મંજૂરી વિના ફરીથી વાંચી શકતું નથી.
