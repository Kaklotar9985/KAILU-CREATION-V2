KAILU CREATION V2 — Firebase Customer Account Loading Spinner Fix

કારણ:
જૂના auth callback માં signed-in Customer માટે ensureCustomerProfile() અને Firestore reads પૂર્ણ થાય ત્યાં સુધી authReady=false રહેતું હતું. Firestore/network request લાંબી અટકે તો આખું My Account Panel "Checking your customer account..." પર જ રહેતું હતું.

સુધારો:
1. Firebase Auth state મળતાં જ Account UI દેખાય છે; profile creation અને checkout-prefill background માં ચાલે છે.
2. શરૂઆતની Auth state માટે 10-second watchdog ઉમેર્યો છે.
3. Customer tab data માટે 12-second timeout, સ્પષ્ટ error અને Retry બટન ઉમેર્યું છે.
4. Module URL version બદલ્યો છે જેથી GitHub Pages પર જૂની cached JavaScript ફરીથી ન આવે.

Deploy:
- આ ZIP ને KAILU-CREATION-V2 repository માં update કરો; V1 repository/domain ન બદલો.
- firebase-config.js માં યોગ્ય existing Firebase Web App config હોવાની ખાતરી કરો.
- Firebase Authentication અને Firestore rules publish થયેલી હોવી જોઈએ.
- GitHub Pages deploy થયા પછી Ctrl+F5 કરો.

Verification limit:
Static code change તૈયાર છે; અહીંથી Firebase project credentials અથવા live Google sign-in session મળ્યા નથી, તેથી live end-to-end login test થયું નથી.
