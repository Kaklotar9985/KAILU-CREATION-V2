KAILU CREATION — Order Success Popup Diagnostic Fix (Gujarati)

આ updateમાં:
- script.js: verification timeout 1.8sથી 6.5s કર્યો (Apps Script cold-start/Sheet read માટે); retries 4 સુધી મર્યાદિત રાખ્યા.
- script.js: endpoint error અથવા callback ન મળ્યે સ્પષ્ટ message આપે છે. Callback missing હોય તો updated Code.gs ને Web Appમાં redeploy કરવાની સૂચના આપે છે. Check Order Status read-only જ છે; તે ફરી POST કરતું નથી.
- Code.gs: action=verifyમાં CacheService/ledger error થાય તો valid JSONP error response આપે છે, જેથી frontend timeoutની જગ્યાએ સમજાય એવો diagnostic આપી શકે.
- Main Orders Sheetના 17 columns બદલ્યા નથી. Meta Pixel ઉમેર્યો નથી.

અત્યંત જરૂરી Deploy Steps:
1. Google Apps Script project ખોલો અને આ ZIPની root Code.gsનો સંપૂર્ણ કોડ paste કરીને Save કરો.
2. setupOrdersSheet() એક વાર Run કરો અને authorization આપો. તે hidden _KAILU_Order_Request_Log ledger તૈયાર કરે છે.
3. Deploy > Manage deployments > Edit (pencil) > Version: New version > Deploy પસંદ કરો. Existing Web App URL જ રાખો. Code Editorમાં Save કરવાથી deployed version બદલાતું નથી.
4. ખાતરી કરો કે script.jsમાં GOOGLE_SCRIPT_URL તે જ Web App URL છે જે redeploy કર્યો છે.
5. Websiteની નવી script.js/index.html GitHub Pages પર commit/publish કરીને Ctrl+F5 કરો.
6. પહેલેથી Orders Sheetમાં દેખાતો Order ફરી submit ન કરો. `Check Order Status` button status verify કરે છે, નવો Order POST કરતું નથી.
