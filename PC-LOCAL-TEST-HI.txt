Windows PC पर चलाने के तरीके:
1. इस ZIP को एक नए folder में Extract करें। पुराने folder के ऊपर overwrite न करें।
2. अंदर वाला KAILU-CREATION-V2-main folder खोलें।
3. File Explorer के address bar में cmd लिखकर Enter दबाएँ।
4. खुली Command Prompt में चलाएँ: py -m http.server 8000
   अगर py command काम न करे: python -m http.server 8000
5. Chrome में खोलें: http://localhost:8000/
6. पहले देखें कि Catalog Google Sheet से load होकर Group Code, Color, in-stock Sizes दिखाता है और Inventory 0 वाला Size नहीं दिखता।
7. Order सिस्टम जाँचने से पहले ध्यान दें: Place Order दबाने पर यह आपके असली Orders Google Sheet में test row जोड़ सकता है और email notification भी भेज सकता है। पहले अपने खुद के नाम से स्पष्ट TEST order डालें, फिर Orders Detail Sheet और email जाँचें।
8. टेस्ट पूरा होने पर Command Prompt में Ctrl+C दबाएँ।

ध्यान:
- GitHub पर कोई file या Commit अभी न करें।
- अगर Catalog fallback products दिखें, Chrome में F12 > Console खोलकर error देखें; Feed URL / permissions / callback की जाँच करें।
- Google Drive images/videos तभी दिखेंगे जब संबंधित file access “Anyone with the link — Viewer” हो।
- Browser JavaScript को server का response पढ़ना संभव न हो सकता है (order request uses no-cors); इसलिए Order saved होने की असली पुष्टि Google Sheet में row और notification email देखकर करें।
