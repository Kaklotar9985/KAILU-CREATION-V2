KAILU CREATION™ — Product Selection Layout Update

यह अपडेट दिए गए product-detail screenshot के अनुसार Catalog cards में ये बदलाव करता है:
- Product title और rating badge
- Selling price, MRP, discount और inclusive-of-tax note
- Google Sheet में एक Group Code के अंतर्गत कई उपलब्ध Colors हों तो image swatches
- Inventory > 0 वाले Size के गोल selectable buttons
- Size Chart button (यह फिलहाल availability/fit guidance दिखाता है; अलग measurement table नहीं)
- Add to Bag, Wishlist और Buy Now controls
- Mobile पर single-column product layout और Desktop पर 3-column layout

Order flow:
- Add to Bag और Buy Now के लिए पहले size चुनना जरूरी है।
- चुना गया Color और Size cart में जाता है, और cart में बदला भी जा सकता है।
- Wishlist इस browser/device की local storage में सेव होती है; यह server/account-synced wishlist नहीं है।
- Existing Cart, pincode validation, Catalog Feed और Orders Web App URLs को बदला नहीं गया है।

Local PC test:
1. ZIP Extract करें।
2. उस folder में जाएँ जहाँ index.html मौजूद है।
3. File Explorer address bar में cmd लिखकर Enter करें।
4. `py -m http.server 8000 --bind 127.0.0.1` चलाएँ।
5. Browser में http://127.0.0.1:8000/index.html खोलें।
6. Size चुनकर Add to Bag, Buy Now, Wishlist, Photo/Video Gallery और Cart टेस्ट करें।
